# John Amodeo

Research on primate visual attention, and production software/agents for biotech. I care about clean, interpretable code, rigor and reproducibility in results and runtimes, and models tested against well-defined targets.

## Projects

- **[asd-neurodev-model](https://github.com/jmamodeo/asd-neurodev-model)** — Python (NumPy) neural-network model of how elevated Wnt and mTOR-activated CCL5 signaling in autism spectrum disorder could slow learning in a visual image-classification network. [doi:10.5281/zenodo.24344589](https://doi.org/10.5281/zenodo.24344589)
- **[benchling-tools](https://github.com/jmamodeo/benchling-tools)** — Preview-then-apply CLI and a read-only-by-default MCP server for Benchling notebooks (Python; unofficial). Also on [PyPI](https://pypi.org/project/benchling-tools/).
- **[image-classifier-lab](https://github.com/jmamodeo/image-classifier-lab)** — *Lessons in AI from an Image Classifier*: a Streamlit teaching lab that trains ResNet-18 in transfer or from-scratch mode, with optional Core ML export timing (Python, PyTorch).
- **[metal-kernels](https://github.com/jmamodeo/metal-kernels)** — Apple Metal GPU kernels for Apple silicon, each with a NumPy reference, Python bindings (MLX and PyTorch MPS), a Swift package, and benchmarks. Currently ships Metal FlashAttention for head dim 32.
